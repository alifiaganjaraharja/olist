# Technical Work Sample: Rigorous Data Auditing, Pipeline Validation, and Integrity Analysis

**Project Overview**
This technical project focuses on building a robust data pipeline to analyze and audit a complex, multi-table marketplace dataset (Olist E-commerce). Using SQL (BigQuery) for advanced data manipulation and Python for preprocessing, the project uncovers operational anomalies, maps data distributions, and ensures systemic data integrity across thousands of transactional records.

Direct Contribution to AI Safety Research (The Critical Part)
While the domain of this specific dataset is e-commerce, the technical methodologies applied are directly foundational to Empirical AI Safety and Data Governance.

Modern machine learning models fail not just because of algorithmic flaws, but due to poisoned, biased, or structurally compromised training data. My ability to track down data drift, isolate systemic anomalies, clean hidden noise, and validate complex relational structures ensures that the 'fuel' feeding an AI system is safe, transparent, and verifiable.

In AI safety research, evaluating a model's alignment requires the exact data auditing skills demonstrated here: ensuring data veracity, understanding edge cases, and preventing biased datasets from creating harmful, unpredictable model outputs.

**Technical Skills Demonstrated**
- Data Veracity & Cleaning: Identifying and handling null fields, broken strings, and mismatched timestamps to prevent data corruption.
- Exploratory Data Analysis (EDA): Mapping distributions to ensure no hidden skews or unrepresented outliers would warp a predictive system.
- Advanced Architecture: Utilizing optimized SQL queries and relational logic to maintain a clear, auditable lineage of data from raw input to final insight.
